Local Page Exporter
PrivacySupport

Save pages. Keep them local.

Capture a web page as PNG or PDF, or create a readable PDF with selectable text.

Local Page Exporter processes captures on your computer. No capture account, analytics, advertising, payment, or capture upload service is included.

Choose the output you need

  • Save PNG / Save PDF: preserve the captured page appearance using screenshots.
  • Text PDF: reflow available page text at a readable size, include available images, then use the browser's Save as PDF print destination.

Choose Full page or Visible area. Keep the source tab active while capture runs. Check the preview for incomplete images, partial captures, or unusual page layouts. Protected browser pages, infinite feeds, embedded content, and remote unloaded slides may not capture fully.

Availability

The first public release is being prepared for Microsoft Edge Add-ons review. After approval, this page can link to the real store listing. No installation link is supplied until a real listing is available.

Your data

Captures remain in the extension's local browser storage until deleted, cleared by the browser, or removed on uninstall. Export important records to a folder you control. Downloads and synchronized folders follow your own device settings. See the privacy policy.
