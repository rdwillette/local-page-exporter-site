Getting started

  1. Open an ordinary web page and click the toolbar icon.
  2. Choose Full page or Visible area, then Capture page. Keep the source tab/window active while it scrolls.
  3. Review the local preview. Save PNG or Save PDF to preserve screenshots.
  4. For readable text, choose Text PDF, set the text size, then Print / Save PDF and the browser's Save as PDF destination. A4 at 100% scale is the tested format.

Common questions

Why does capture stop when I switch tabs? Capture reads the active source tab. Keep it active until completion. Available sections remain as a partial capture.

Why is text not selectable in Save PDF? That output contains screenshots. Choose Text PDF for available real page text. There is no OCR.

Why is something missing? Expand hidden sections first. Some protected, embedded, virtualized, animated, or unloaded content needs different handling. Review the warning and preview. Refresh the page and make a fresh capture if it was interrupted.

Where is my data? In local extension browser storage and files you exported. Use the trash controls to delete stored captures; downloads are separate. Removing the extension can remove its stored captures.

Report a problem

Include the extension/browser version, operating system, Full page or Visible area, output type, warning text, and steps to reproduce. A public example URL helps if you can share one. Do not send confidential screenshots, captured documents, or account credentials.
